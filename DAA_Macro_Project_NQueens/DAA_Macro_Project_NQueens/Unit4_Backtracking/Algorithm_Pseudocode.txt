ALGORITHM: N-QUEENS USING BACKTRACKING

NQueens(row)
1. If row == N:
      Print the board
      Return true
2. For col = 0 to N-1:
3.     If isSafe(row, col):
4.         Place a queen at (row, col)
5.         If NQueens(row + 1) is true:
               Return true
6.         Remove the queen
           // Backtrack
7. Return false

isSafe(row, col)
1. Check all previously placed queens.
2. Reject if another queen is in the same column.
3. Reject if another queen is on the same diagonal.
4. Otherwise return true.
