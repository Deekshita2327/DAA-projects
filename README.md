# DAA Projects

This repository contains the DAA (Design and Analysis of Algorithms) project files organized into folders.

## Folders
- `DAA_Macro_Project_Project135t7/`
- `unit 1 sorting/`
- `DAA_Macro_Project_NQueens/`
- `DAA_Macro_Project_Project9/`
- `Strassen_Matrix_Multiplication_Project/`

Each folder contains the files extracted from its corresponding uploaded ZIP archive.

## Upload to GitHub
1. Extract/download this folder on your computer.
2. Open the GitHub repository where you want to store these projects.
3. Choose **Add file → Upload files**.
4. Upload the contents of `DAA_GitHub_Projects` (including the five project folders and this README).
5. Commit the changes.
