# 📘 Design and Analysis of Algorithms (DAA) Projects

Welcome to the **DAA Projects Repository**! This repository contains implementations and academic projects focused on fundamental algorithms and problem-solving techniques studied in Design and Analysis of Algorithms.

The projects demonstrate how algorithms work, how they can be implemented, and how different approaches help solve computational problems efficiently.

## 📂 Projects Included

### 1. DAA Macro Project – Project 13
An algorithm-based project focused on applying concepts from Design and Analysis of Algorithms to solve a computational problem.

### 2. Unit 1 – Sorting Algorithms
Implementations of sorting techniques used to arrange data in a specific order.

**Concepts covered:**
- Sorting and ordering of elements
- Algorithm execution and comparisons
- Time complexity analysis
- Comparison of sorting techniques

### 3. DAA Macro Project – N-Queens Problem
A classic combinatorial problem that involves placing N queens on an N × N chessboard so that no two queens attack each other.

**Concepts covered:**
- Backtracking
- Constraint satisfaction
- Recursive problem-solving
- Search-space exploration

### 4. DAA Macro Project – Project 9
An additional algorithmic project demonstrating the application of DAA concepts to computational problem-solving.

### 5. Strassen's Matrix Multiplication
An efficient matrix multiplication algorithm that uses a divide-and-conquer approach to reduce the number of recursive multiplications.

**Concepts covered:**
- Divide and conquer
- Matrix multiplication
- Recursive algorithms
- Time complexity analysis
